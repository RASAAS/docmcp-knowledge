# NMPA Technical Documentation

Medical device registration technical documentation requirements under NMPA (National Medical Products Administration) are defined by the **Administrative Measures for Medical Device Registration and Filing** (Order No. 47, 2021) and **Notice 2021-121** (Attachment 5: Registration Dossier Requirements and Instructions).

## Key Differences from EU MDR

| Aspect | NMPA | EU MDR |
|--------|------|--------|
| Structure | 6 chapters | Annex II (7 sections) + Annex III |
| Clinical evaluation | Equivalent device / Clinical trial / Exemption list | CEP + CER + PMCF (mandatory for all classes) |
| Type testing | Mandatory at NMPA-designated laboratories | NB decides testing scope |
| Product Technical Requirement | Unique NMPA document (产品技术要求) | No direct equivalent |
| Essential Principles | 安全和性能基本原则清单 (Attachment 9) | GSPR Annex I checklist |
| Software | Separate detailed requirements (AI, cybersecurity, interoperability) | Integrated into V&V section |
| QMS | Full QMS documentation in submission (Ch.6) | QMS assessed separately during NB audit |
| Post-market | Not part of registration dossier | Annex III (PMS Plan, PSUR) |
| Language | Chinese mandatory; foreign docs need translated copies | NB language preference |

## Notes for CRO

- NMPA submissions are significantly more procedural than EU MDR -- strict format compliance is essential
- Import device registration requires: authorized representative (代理人), notarized documents, Chinese translations
- Product Technical Requirement is a standalone document with specific NMPA formatting rules
- Type testing at designated labs can take 3-6 months -- plan timeline accordingly
- Clinical evaluation via equivalent device pathway is the most common approach but requires detailed comparison
- QMS inspection (质量管理体系核查) is a separate NMPA audit process for domestic and import devices
