# Chapter 4: Clinical evaluation

**Source:** NMPA Announcement No. 121 of 2021, Annex 5, Chapter 4  
**Electronic directories:** domestic Class III registration dossier; imported Class II and Class III registration dossier

Section titles follow those electronic directories. The text under each section is a close translation of the official Chinese wording in Annex 5. Where a directory states the same point differently, that wording is included. A folder that has a name and no further official text is listed by name only.

Opening sentence of Annex 5 for this chapter: for Class II and Class III medical devices that require clinical evaluation, provide the clinical evaluation data as required.

## CH4.1 Table of contents

The submitted dossier shall include a table of contents, covering every heading and subheading of this chapter, and shall state the contents number, the contents title, applicability, the uploaded file name, and the page numbers of the uploaded file, and shall give the page number of each item. Applicability shall state whether a CR folder applies.

Annex 5: the table of contents shall include every heading and subheading of this chapter and the page number of each item.

## CH4.2 Summary of clinical supporting documents

The domestic Class III directory and the imported Class II and Class III directory have only this folder name. The requirements are under the headings below.

### CH4.2.1 Clinical evaluation data

Domestic Class III directory: for a medical device that requires clinical evaluation, provide the clinical evaluation data as required.

The imported Class II and Class III directory, and Annex 5: for a Class II or Class III medical device that requires clinical evaluation, provide the clinical evaluation data as required.

1. Product description and development background: basic information on the device, the scope of application, existing diagnostic or treatment methods and the clinical use of the medical devices involved, the relationship of the device to existing diagnostic or treatment methods, and the clinical effect expected to be achieved.
2. State the scope covered by the clinical evaluation. If part of the device may be exempt from clinical evaluation, describe its structure and composition and state the reason for the exemption.
3. Clinical evaluation pathway: according to the scope of application, technical characteristics, and existing clinical data, choose an appropriate pathway, including the equivalent-device pathway and/or the clinical-trial pathway.
4. If evaluation is by the equivalent-device pathway, submit comparison data between the device and the equivalent device as to scope of application, technical characteristics, and biological characteristics. Collect, assess, and analyse the clinical data of the equivalent device and form the clinical evidence. Where applicable, describe the differences and submit sufficient scientific evidence that the two have the same safety and effectiveness.

### CH4.2.2 Clinical trial data

If evaluation is by the clinical-trial pathway, submit the clinical trial protocol, the clinical trial report, and a sample informed-consent form, and attach the clinical trial database (the raw database, the analysis database, the explanatory documents, and the program code).

Annex 5 also includes, in the same sentence, the written opinion of the ethics committee of the clinical trial institution agreeing that the trial may be conducted. The electronic directories place that sentence under CH4.3.

The study folder “[trial description, protocol number, start date]”, and under it “clinical trial summary”, “clinical trial report”, and “clinical trial data”, have only folder names in both directories and no further requirement.

### CH4.2.3 Clinical literature review and other related materials

The domestic Class III directory and the imported Class II and Class III directory have only this folder name and no further requirement.

## CH4.3 Ethics committee approval documents

The written opinion of the ethics committee of the clinical trial institution agreeing that the clinical trial may be conducted.

## CH4.4 Clinical trial sites and ethics committee contact information

The domestic Class III directory and the imported Class II and Class III directory have only this folder name and no further requirement.

## CH4.5 Other clinical evidence

Where applicable, provide the abstract, report, and data of the evaluation for the corresponding item.

The study folder “[study description, study number, start date]”, and under it “summary”, “full report”, and “statistical data”, have only folder names in both directories and no further requirement.
