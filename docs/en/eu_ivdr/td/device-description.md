# Device Description & Specification (IVDR)

**IVDR reference:** Annex II, Section 1  
**BPG reference:** Team-NB BPG-IVDR V2 (2025-09-03), Device Description & Specifications (approx. pp. 7–10)  
**Document code:** AII-S1  
**Owner:** Manufacturer  
**Service mode:** Assisted (Reguverse: **mandatory gate before PE / GSPR**)

## Checklist

### 1.1 Device description and specification details

#### (a) Name, general description, intended purpose

- [ ] Device or trade name and general description including intended purpose
- [ ] Name matches the application (same language)
- [ ] Intended purpose detailed enough: analyte/measurand; function (screening/monitoring/diagnosis/aid, etc.); intended users (HCP/lay); specimen types; population; qualitative/semi-/quantitative; CDx drug link if applicable
- [ ] Intended patient population; exclusion statements in IFU reflected in TD and aligned with clinical performance
- [ ] Intended user and use environment clearly described and supported by clinical performance
- [ ] EMDN code details
- [ ] Single-use / multi-use / sterile information; components and accessories as applicable
- [ ] Table of each variant/model/configuration/component/accessory in scope with identifiers (catalogue/model/UDI, etc.)

#### (b) Basic UDI-DI

- [ ] Basic UDI-DI per Annex VI Part C
- [ ] Consistency throughout the TD
- [ ] For devices under one Basic UDI-DI: describe differences and grouping rationale

#### (c)–(f) Intended-purpose elements, principle, qualification, classification

- [ ] All Annex II 1.1(c) elements complete
- [ ] Detailed assay method / principle of operation
- [ ] Rationale for qualification as an IVD device (incl. specimen receptacles where relevant)
- [ ] Risk class and Annex VIII rule justification; strictest applicable rule; multi-test devices classified individually with highest class for the overall device

#### (g)–(m) Novelty, combinations, specimens, instruments, software, configurations, accessories

- [ ] Novel features and impact on safety/performance (or explicit “none”)
- [ ] Combinations with other devices/products and compatibility evidence
- [ ] Specimen collection/transport materials supplied or recommended; pre-analytical requirements
- [ ] Instruments for automated assays: compatibility evidence with dedicated assays (part of PE)
- [ ] Automated assays: instrumentation characteristics / application sheets
- [ ] Software used/recommended with the device, including version
- [ ] Complete list of configurations/variants to be placed on the market
- [ ] Accessories / other devices / non-devices required for correct function; MDR accessories (e.g. lancet) with Certificate/DoC

### 1.2 Previous and similar generations

- [ ] Overview of previous generation(s) by the manufacturer, if any
- [ ] For initial IVDR applications: prior IVDD self-declaration or NB certification; changes vs IVDD-certified device
- [ ] Market history (EU and other geographies); explicitly state if never marketed
- [ ] Overview of similar devices on Union/international markets with key specification comparison, if any

## Common NB gaps

- Incomplete intended-purpose elements or misalignment with IFU / PE
- Inconsistent variants / accessories / UDI / DoC / labelling
- Missing IVDD→IVDR change history or market history
