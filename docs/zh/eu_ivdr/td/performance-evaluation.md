# 性能评价（PEP / PER）（IVDR）

**IVDR 参考：** 第 56 条、附件十三  
**BPG 参考：** Team-NB BPG-IVDR V2（2025-09-03）Performance Evaluation（约第 31–33 页）  
**文件代码：** AII-S6-PE

性能评价是**持续过程**：科学有效性、分析性能、临床性能 → **PER**，并由 **PMPF** 驱动上市后更新（C/D 类必要时至少每年更新）。

## 要求清单

### 性能评价计划（PEP）

- [ ] PEP 覆盖科学有效性、分析性能、临床性能三支柱及方法学
- [ ] 与预期用途、风险管理、IFU 声称一致
- [ ] 明确数据来源：文献、已建立科学、性能研究、等同/历史数据等及正当性
- [ ] 缺口与残余不确定性及后续行动（含 PMPF 触发）

### 分析性能 / 临床性能

- [ ] 分析性能特征按附件一 9.1(a) 等适用项证明（特异性、灵敏度/LoD、正确度、精密度、测量区间等）
- [ ] 临床性能证明附件一 9.1(b) 相关特征；临床性能研究除非有正当理由可依赖其他来源
- [ ] 自测/床旁：额外验证与可用性证据挂钩

### 性能评价报告（PER）

- [ ] PER 综合三支柱结论、受益-风险、局限性与 PMPF 计划概要
- [ ] 与标签/IFU/SSP（如适用）声称一致
- [ ] 生命周期更新：纳入 PMPF/PMS/新文献后的变更说明
