# 器械描述与规格（IVDR）

**IVDR 参考：** 附件二，第 1 节  
**BPG 参考：** Team-NB BPG-IVDR V2（2025-09-03）Device Description & Specifications（约第 7–10 页）  
**文件代码：** AII-S1  
**责任方：** 制造商  
**服务模式：** 协助（Reguverse：**执行 PE / GSPR 前的强制前置**）

## 要求清单

### 1.1 器械描述与规格细节应包括

#### (a) 名称、一般描述与预期用途

- [ ] 器械或商品名称，以及一般描述（含预期用途/预期目的）
- [ ] 名称与申请文件一致（且语言一致）
- [ ] 预期用途足够具体：检测/测量对象；功能（筛查/监测/诊断/辅助诊断等）；预期使用者（专业/外行）；标本类型；适用人群；定性/半定量/定量；伴随诊断关联药品信息（如适用）
- [ ] 预期患者人群；若无特定人群，IFU 中排除声明须在 TD 中体现并与临床性能一致
- [ ] 预期使用者与使用环境在 TD 中清晰描述，并由临床性能评价结果支持
- [ ] EMDN 编码详情
- [ ] 一次性/多次使用/无菌等说明；组件与附件（适用时）
- [ ] 提交范围内每个变体/型号/配置/组件/附件的表格：标识符（目录号/型号/UDI 等）

#### (b) Basic UDI-DI

- [ ] 按附件六 C 部分分配的 Basic UDI-DI
- [ ] 全套 TD 中 Basic UDI-DI 一致
- [ ] 同一 Basic UDI-DI 下多器械：说明差异及为何同组

#### (c)–(f) 预期用途要素、原理、定性与分类

- [ ] 附件二 1.1(c) 各子项（检测对象、功能、使用者、标本、人群、定性/定量等）完整
- [ ] 检测方法原理或器械工作原理的详细描述
- [ ] 产品作为 IVD 器械的定性论证（含标本容器等边界情形）
- [ ] 按附件八的风险等级与分类规则论证；多规则取最严；多检测项目分别分类并取最高等级适用于整机

#### (g)–(m) 新颖性、组合使用、标本、仪器、软件、配置、附件

- [ ] 新颖特征描述及对安全/性能影响（或明确声明无新颖特征）
- [ ] 与其他器械/产品组合使用的描述及兼容性证据
- [ ] 随附或推荐的标本采集/运输材料及分析前要求（如分析物稳定性）
- [ ] 自动化仪器：与适用/专用检测的兼容性证据（性能评价一部分）
- [ ] 自动化检测：适用仪器特征/应用表
- [ ] 与器械一并使用或推荐的软件描述及版本
- [ ] 拟上市的全部配置/变体完整清单
- [ ] 附件、其他器械及非器械产品（如缓冲液、提取试剂盒）描述；若附件属 MDR 器械（如采血针），提供证书/DoC

### 1.2 既往代次与类似器械

- [ ] 制造商既往代次概览（如存在）
- [ ] IVDR 初始申请：是否曾按 IVDD 自我宣告或 NB 认证上市；相对 IVDD 认证版本的变更
- [ ] 市场历史（欧盟及其他地区）；全新器械明确声明从未上市
- [ ] 欧盟或国际市场上类似器械概览及关键规格对比（如存在）

## NB 常见不足

- 预期用途要素不完整或与 IFU / 性能评价不一致
- 变体/附件/UDI/DoC/标签不一致
- 缺少 IVDD→IVDR 变更或市场历史
