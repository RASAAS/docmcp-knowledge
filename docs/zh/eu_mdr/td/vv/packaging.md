# 包装验证

**MDR 参考:** 附录II, 第6.1.4节; 附录I GSPR 11.5  
**服务项目ID:** `mdr_sec06_packaging`  
**适用范围:** 无菌器械、需要屏障完整性的包装器械

## 概述

包装验证证明无菌屏障系统(SBS)和防护包装在声称的货架期和配送周期内维持器械无菌性和物理保护。主要标准是EN ISO 11607系列。

## 现行标准: EN ISO 11607

**EN ISO 11607-1:2020+A1:2023**（包装要求）和**EN ISO 11607-2:2020**（成型、密封和组装过程的验证要求）。

> **协调状态:** 截至2026年，ISO 11607未列为MDR下的协调标准。合规性须独立证明。但它仍是普遍接受的最新技术水平标准。

## 关键交付物

| 文件 | 描述 |
|------|------|
| 包装BOM | 所有包装组件的材料、规格、供应商 |
| 密封强度验证 | 剥离/爆破测试方案和报告 |
| 包装完整性测试 | 染料渗透、气泡泄漏或目视检查 |
| 配送模拟 | ASTM D4169或ISTA方案测试 |
| 加速和实时老化 | 包装系统的货架期测试 |
| 最坏情况配置 | 测试样品选择的论证 |

## GSPR映射

| GSPR | 要求 |
|------|------|
| 11.5 | 安全的储存、运输和条件 |
| 6.6 | 货架期通过适当测试支持 |
