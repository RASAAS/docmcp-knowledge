# 测量/诊断功能验证

**MDR 参考:** 附录I, GSPR 15; 分类规则10 (I(m)类)  
**服务项目ID:** `mdr_sec06_measuring`  
**适用范围:** 具有测量功能的器械、诊断器械

## 概述

具有测量或诊断功能的器械必须证明其测量能力的准确性、精密度和可靠性。MDR GSPR 15建立了具体要求，规则10可能触发测量器械的I(m)类分类。

## 关键交付物

| 文件 | 描述 |
|------|------|
| 测量性能规格 | 准确度、精密度、范围、分辨率 |
| 校准方案与报告 | 计量溯源证据 |
| 分析性能报告 | 重复性、重现性、线性、干扰 |
| 临床性能数据 | 灵敏度、特异性（如适用） |
| 测量精度标签 | MDR附录I GSPR 15要求 |

## GSPR映射

| GSPR | 要求 |
|------|------|
| 15.1 | 测量器械须按准确性和稳定性设计 |
| 15.2 | 测量值以法定单位表示 |
| 15.3 | 标明精度限值 |
