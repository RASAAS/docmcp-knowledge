# 植入物MRI安全性

**MDR 参考:** 附录I, GSPR 14.6  
**服务项目ID:** `mdr_sec06_mri_safety`  
**适用范围:** 植入器械（不含纯软件）

## 概述

植入器械必须进行MRI安全性评估，以确定其条件性标签状态（MR不安全、MR条件性、MR安全）。测试遵循ASTM标准和ISO/TS 10974（有源植入器械）。

## 关键标准

| 标准 | 标题 |
|------|------|
| ASTM F2052 | 磁致位移力 |
| ASTM F2213 | 磁致扭矩 |
| ASTM F2119 | 加热 -- 无源植入物 |
| ASTM F2182 | RF致加热 |
| ISO/TS 10974:2018 | 有源植入器械 -- MRI安全 |

## MRI标签类别

| 类别 | 定义 |
|------|------|
| **MR安全** | 在所有MRI环境中无已知危害 |
| **MR条件性** | 在指定MRI条件下安全（磁场强度、SAR、梯度） |
| **MR不安全** | 在所有MRI环境中已知存在危害 |

## 关键交付物

| 文件 | 描述 |
|------|------|
| MRI安全性评估报告 | 测试结果和标签确定 |
| 位移力测试 (F2052) | 偏转角测量 |
| 扭矩测试 (F2213) | 磁致扭矩测量 |
| RF加热测试 (F2182) | RF暴露下的温升 |
| 伪影评估 (F2119) | 图像畸变表征 |
