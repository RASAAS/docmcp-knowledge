# 器械互联互操作性测试

**MDR 参考:** 附录I, GSPR 14.5  
**服务项目ID:** `mdr_sec06_interop`  
**适用范围:** 与其他器械或系统有接口的有源器械

## 概述

互操作性测试证明医疗器械可以安全有效地与其设计交互的其他器械和系统交换数据和功能。MDR GSPR 14.5要求设计为与其他器械组合使用的器械不得损害安全性和性能。

## 关键交付物

| 文件 | 描述 |
|------|------|
| 接口规范 | 协议、连接器、数据格式 |
| 互操作性测试计划 | 器械组合的测试场景 |
| 互操作性测试报告 | 组合测试结果 |
| 组合风险评估 | 器械交互的危害 |

## GSPR映射

| GSPR | 要求 |
|------|------|
| 14.5 | 组合器械：安全性和性能保持 |
