# 稳定性与货架期验证

**MDR 参考:** 附录II, 第6.1.4节; 附录I GSPR 6.6  
**服务项目ID:** `mdr_sec06_stability`  
**适用范围:** 有货架期声明的非软件器械

## 概述

稳定性和货架期验证证明器械在其声称的货架期内保持安全性和性能特征。包括器械本身和包装。这不同于[器械使用寿命验证](./device-lifetime)，后者涵盖使用期间。

## 关键标准

| 标准 | 标题 | 范围 |
|------|------|------|
| ASTM F1980 | 无菌屏障系统的加速老化 | 基于Arrhenius的加速老化方法 |
| ASTM D4169 | 运输容器的性能测试 | 运输模拟和配送环境 |
| EN ISO 11607-1:2020+A1:2023 | 终端灭菌医疗器械的包装 -- 第1部分 | 包装系统要求 |

## 关键交付物

| 文件 | 描述 |
|------|------|
| 货架期声明论证 | 声称有效期的理由 |
| 加速老化方案与报告 | 试验设计、Q10因子、温度、持续时间、结果 |
| 实时老化计划 | 同步实时研究设计 |
| 运输模拟报告 | ASTM D4169或ISTA方案测试 |
| 老化后功能测试 | 老化暴露后的器械性能 |

## GSPR映射

| GSPR | 要求 |
|------|------|

| 11.5 | 安全的运输和储存条件 |
