# 人体源组织器械

**MDR 参考:** 附录I, GSPR 13.2; 附录II, 第6.2.2节  
**服务项目ID:** `mdr_sec06_human_tissue`  
**适用范围:** 含有人体组织或细胞衍生物质的器械

## 概述

使用人体源组织、细胞或物质制造的器械必须解决特定风险，包括TSE/CJD传播，并符合供体选择、溯源和加工验证要求。

## 关键交付物

| 文件 | 描述 |
|------|------|
| TSE/CJD风险评估 | 朊病毒传播风险分析 |
| 供体选择与筛查 | 供体资格标准和测试 |
| 来源溯源文档 | 从供体到器械的完整监管链 |
| 加工验证 | 病毒/因子灭活研究 |
| 伦理合规 | 知情同意文档、监管审批 |

## GSPR映射

| GSPR | 要求 |
|------|------|
| 13.2 | 含人体组织的器械：来源溯源、病毒灭活 |
