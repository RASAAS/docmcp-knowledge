# 器械使用寿命验证

**MDR 参考:** 附录I, GSPR 6.6; 附录II, 第6.1节  
**服务项目ID:** `mdr_sec06_lifetime`  
**适用范围:** 非软件医疗器械（不同于货架期）

## 概述

器械使用寿命验证证明器械在其定义的操作寿命内保持安全性和性能。MDR GSPR 6.6要求制造商定义器械使用寿命并提供支持证据。这不同于[货架期](./stability-shelf-life)，后者涵盖首次使用前的存储期。

## 关键交付物

| 文件 | 描述 |
|------|------|
| 寿命定义与论证 | 声称寿命的理由 |
| 寿命终点功能测试 | 模拟寿命使用后的性能数据 |
| 疲劳/磨损分析 | 机械测试（循环载荷、磨损颗粒） |
| 降解评估 | 寿命期内材料性能变化 |
| 临床数据支持 | 支持寿命声明的临床证据 |

## GSPR映射

| GSPR | 要求 |
|------|------|
| 6.6 | 器械使用寿命通过适当测试定义和证明 |
| 1 | 器械在整个寿命期内安全且按预期性能运行 |
