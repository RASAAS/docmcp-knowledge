# 技术文件封面信

**MDR 参考：** 无（NB行政要求）  
**BPG Rev.4 参考：** 通用考虑（第5-10页）  
**文件代码：** AII-COVER  
**责任方：** CRO / 制造商  
**服务模式：** 协助

## 要求清单

### 封面信内容

- [ ] 申请类型（初次MDR、转移、续期、重大变更）
- [ ] 器械标识（商品名、基本UDI-DI、产品代码）
- [ ] 器械分类及适用的分类规则
- [ ] TD提交范围（器械家族、变体、涵盖的附件）
- [ ] 索引/目录（含TD各章节的超链接）
- [ ] 确认NB的提交偏好（格式、语言、结构）
- [ ] MDD到MDR过渡：此前NB评估参考编号
- [ ] 与NB的提交前沟通摘要
- [ ] 提交语言记录
- [ ] 制造商法规团队联系信息

### 提交格式（依据BPG Rev.4 通用考虑）

- [ ] 首选PDF格式；MS Office亦可接受
- [ ] 无扫描文件
- [ ] 文件路径+名称 < 160字符（Windows兼容性）
- [ ] 单个PDF不超过100 MB
- [ ] PDF文件有书签；10页以上的文件有内部目录
- [ ] 参照IMDRF/RPS WG (PD1)/N27R2提交结构
- [ ] 考虑IMDRF/RPS WG/N9 FINAL:2024（第4版）nIVD目录原则

### 利用既往评估

- [ ] 曾由同一NB在MDD/MDR下评估的器械：
  - [ ] 引用此前的审查编号/项目编号
  - [ ] 明确标示已变更和未变更的证据/数据
  - [ ] 记录与此前评估相比的变更程度
  - [ ] GSPR清单中包含对此前已评估证据的引用
