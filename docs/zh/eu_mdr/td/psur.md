# 定期安全性更新报告 (PSUR)

**MDR 参考：** 第86条；附录III  
**BPG Rev.4 参考：** 第7.2节（第90-92页）  
**文件代码：** AIII-PSUR  
**责任方：** CRO  
**服务模式：** 仅编写

## 适用范围

- **必需：** IIa类、IIb类和III类器械
- **更新频率（依据第86条）：**
  - IIa类：至少每2年
  - IIb / III类：至少每年
- **I类器械：** 按第85条提交PMS报告（非PSUR）

## 要求清单

### 内容（依据第86条和附录III）

- [ ] 报告期内PMS数据分析的总结
- [ ] 基于PMS数据的风险-收益评估结论
- [ ] PMCF活动的主要发现
- [ ] 销售量数据（售出单位数）和使用人群估算
- [ ] 投诉总结（按类型和频率分类）
- [ ] 报告期内报告的严重事件和FSCA
- [ ] 与PMS计划指标和阈值对比的趋势分析
- [ ] PMS发现所采取的行动（CAPA、设计变更、标签更新）
- [ ] 结论和建议：
  - [ ] 风险-收益比仍然可接受
  - [ ] 优化安全性和性能的行动
  - [ ] TD的必要更新（CER、RMR、IFU、GSPR等）
- [ ] 引用PMCF评价报告发现
- [ ] 触发SSCP更新（如适用）

### 生命周期整合

- [ ] PSUR结论反映在下一次CER更新中
- [ ] PSUR发现反馈到风险管理文件
- [ ] PSUR触发PMS计划更新（如需要）
- [ ] 与SSCP年度审查一致
- [ ] 与NB监督计划一致

### 提交

- [ ] 上传至EUDAMED（功能可用时）
- [ ] 提供给NB评估
- [ ] EUDAMED不可用时：遵循NB特定的提交安排（依据MDCG 2021-1）

## 常见问题（来自BPG Rev.4）

- PSUR更新频率不符合MDR第86条要求
- 趋势分析不完整或与PMS计划指标无关联
- 收益部分是CER的重复叙述而非新上市后数据的分析
- 所采取的行动未明确关联到具体的PMS发现
- 严重事件分析缺乏根本原因调查
- PSUR与PMCF报告和SSCP更新不一致

## 依赖关系

PSUR为 **Phase 5**（认证后生命周期）交付物：
- 依赖于 **PMS计划**（定义数据收集范围）
- 整合 **PMCF报告** 发现
- 触发 **CER**、**RMR**、**IFU**、**SSCP** 更新
- 为NB年度监督审查提供输入
