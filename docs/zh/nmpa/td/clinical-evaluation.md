# 第4章：临床评价资料

**法规依据：** 2021年第121号公告 附件5 第4章  
**电子目录：** 境内第三类医疗器械注册申报资料电子目录；进口第二类、三类医疗器械注册申报资料电子目录

下列各节标题采用上述电子目录的文件夹名称。各节说明采用公告附件5的原文；电子目录对同一事项另有表述的，一并写明。电子目录中只有文件夹名称、没有另写要求的，只列名称。

公告附件5章首：需要进行临床评价的第二类、第三类医疗器械，按照相关要求提供临床评价资料。

## CH4.1 章节目录

应有所提交申报资料的目录，包括本章的所有标题和小标题，写明目录序号、目录标题、适用情况、上传文件名称、上传文件页码，注明目录中各内容的页码。适用情况应列明 CR 目录是否适用。

公告附件5：应当包括本章的所有标题和小标题，注明目录中各内容的页码。

## CH4.2 临床支持性文件综述

境内第三类、进口第二类和三类电子目录只有该文件夹名称，要求写在下级标题中。

### CH4.2.1 临床评价资料

境内第三类电子目录：需要进行临床评价的医疗器械，按照相关要求提供临床评价资料。

进口第二类、三类电子目录与公告附件5：需要进行临床评价的第二类、第三类医疗器械，按照相关要求提供临床评价资料。

1. 产品描述和研发背景：包括申报产品基本信息、适用范围、现有的诊断或治疗方法及涉及医疗器械的临床应用情况、申报产品与现有诊断或治疗方法的关系、预期达到的临床疗效等。
2. 明确临床评价涵盖的范围，申报产品中如有可免于进行临床评价的部分，描述其结构组成并说明免于进行临床评价的理由。
3. 临床评价路径：根据申报产品的适用范围、技术特征、已有临床数据等具体情况，选择恰当的临床评价路径，包括同品种临床评价路径和/或临床试验路径。
4. 若通过同品种临床评价路径进行临床评价，应当提交申报产品与同品种医疗器械在适用范围、技术特征、生物学特性方面的对比资料；应当对同品种医疗器械的临床数据进行收集、评估和分析，形成临床证据。如适用，应当描述申报产品与同品种医疗器械的差异，提交充分的科学证据证明二者具有相同的安全有效性。

### CH4.2.2 临床试验资料

若通过临床试验路径进行临床评价，应当提交临床试验方案、临床试验报告、知情同意书样本，并附临床试验数据库（原始数据库、分析数据库、说明性文件和程序代码）。

公告附件5在同一句中还写有：临床试验机构伦理委员会同意开展临床试验的书面意见。电子目录将该句写在 CH4.3。

研究资料文件夹「[试验描述、方案编号、起始日期]」，以及其下「临床试验概要」「临床试验报告」「临床试验数据」，两份电子目录只有文件夹名称，没有另写要求。

### CH4.2.3 临床文献综述及其他相关资料

境内第三类、进口第二类和三类电子目录只有该文件夹名称，没有另写要求。

## CH4.3 伦理委员会批准的相关文件

临床试验机构伦理委员会同意开展临床试验的书面意见。

## CH4.4 临床试验地点和伦理委员会联系信息

境内第三类、进口第二类和三类电子目录只有该文件夹名称，没有另写要求。

## CH4.5 其他临床证据

如适用，提供相应项目评价资料的摘要、报告和数据。

研究资料文件夹「[研究介绍、研究编号、起始日期]」，以及其下「总结」「完整报告」「统计数据」，两份电子目录只有文件夹名称，没有另写要求。
