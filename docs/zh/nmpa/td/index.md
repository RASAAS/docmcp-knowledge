# NMPA 注册申报资料

医疗器械注册申报资料的内容要求见《关于公布医疗器械注册申报资料要求和批准证明文件格式的公告》（2021年第121号）。电子申报文件夹见相应 RPS 目录。各页标题用电子目录的文件夹名称，说明用公告原文；目录写得不一样的，两处都写出。

本页所列是医疗器械目录。体外诊断试剂、高风险医疗器械临床试验审批、说明书更改告知各自另有电子目录，不在下列各页中复述。

## 按注册情形

| 情形 | 资料依据 | 电子目录 | 说明 |
|------|----------|----------|------|
| 首次注册 | 121号公告附件5 | 境内第三类；进口第二类、三类 | 下列各章 |
| [变更注册](/zh/nmpa/td/change-registration) | 121号公告附件7 | 境内变更注册；进口变更注册 | 以变更事项组织 |

| [延续注册](/zh/nmpa/td/renewal) | 121号公告附件6 | 境内延续注册；进口延续注册 | 第2、5、6章整章不适用 |

## 首次注册电子目录

公告附件5按 1.监管信息至 6.质量管理体系文件列二级标题。境内第三类与进口第二类、三类电子目录的文件夹编号与这些二级标题不是同一套编号。各章页面按电子目录编号书写。

| 章 | 电子目录中有资料要求的文件夹 |
|----|------------------------------|
| [第1章 监管信息](/zh/nmpa/td/regulatory-info) | CH1.2 章节目录，CH1.3 术语、缩写词列表，CH1.4 申请表，CH1.5 产品列表，CH1.6 质量管理体系、全面质量体系或其他证明文件，CH1.9 申报前联系情况和与监管机构的既往沟通记录，CH1.11 符合性陈述/认证/声明及其下级，CH1.12 主文档授权信，CH1.14 其他监管信息。进口另有 CH1.7 自由销售证书/上市证明文件、CH1.13 代理人委托书 |
| [第2章 综述资料](/zh/nmpa/td/product-summary) | CH2.2 申报综述，CH2.4 产品描述及其下级，CH2.5 适用范围和/或预期用途及禁忌证及其下级，CH2.6 全球上市历程及其下级，CH2.7 其他申报综述信息 |
| [第3章 非临床资料](/zh/nmpa/td/non-clinical) | CH3.2 风险管理，CH3.3 医疗器械安全和性能基本原则（EP）清单，CH3.4 标准（CH3.4.1 标准列表，CH3.4.2 符合性声明和/或认证；没有 CH3.4.3），CH3.5 非临床研究及其下级，CH3.6 非临床研究文献，CH3.7 货架有效期和包装验证，CH3.8 其他资料 |
| [第4章 临床评价资料](/zh/nmpa/td/clinical-evaluation) | CH4.2.1 临床评价资料，CH4.2.2 临床试验资料，CH4.3 伦理委员会批准的相关文件，CH4.5 其他临床证据 |
| [第5章 产品说明书和标签样稿](/zh/nmpa/td/ifu-labels) | CH5.2 产品/包装标签，CH5.3 使用说明书，CH5.10 其他说明书标签材料 |
| [第6章](/zh/nmpa/td/qms) | 第6A章质量管理体系文件（CH6A.1 至 CH6A.9），第6B章申报器械的质量管理体系信息（CH6B.2） |
