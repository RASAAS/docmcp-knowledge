# 欧盟医疗器械可用性监测仪表盘3.5版发布：多源数据驱动的供应链透明度与过渡期合规新基准

## 一、政策背景与意义

### 1.1 MDR/IVDR过渡实施中的市场可及性隐忧

自《医疗器械法规》（Regulation (EU) 2017/745, 以下简称MDR）于2021年5月26日正式适用、以及《体外诊断医疗器械法规》（Regulation (EU) 2017/746, 以下简称IVDR）于2022年5月26日正式适用以来，欧盟医疗器械监管体系经历了数十年来最深刻的范式转换。新法规大幅提升了临床证据要求、强化了公告机构（Notified Bodies, NBs）的指定与监督标准，并显著扩展了上市后监督与警戒义务。然而，这一高标准的监管框架在实践中也引发了广泛的市场结构性焦虑：公告机构指定速度与产能是否足以消化大量待转换的证书？中小企业是否有足够资源完成技术文件升级？部分器械——尤其是低批量、高临床价值的利基产品——是否会因合规成本过高而被迫退出欧盟市场？

为回应上述关切，欧盟立法机构先后通过了《条例（EU）2023/607》与《条例（EU）2024/1860》，分别延长了MDR与IVDR的过渡期，并在MDR与IVDR中引入了第10a条，要求制造商在预期供应中断或终止前至少6个月向主管当局、公告机构及相关经济运营商发出通知。这一"供应中断预警"机制的核心目的在于保障患者与使用者的器械可及性，防止过渡期合规压力转化为事实上的临床供应危机。

然而，法律义务的设定并不自动产生监管洞察力。欧盟委员会亟需一个实证基础，用以系统评估MDR/IVDR过渡对器械市场准入的实际影响——哪些器械类别正在减少、哪些成员国或产品领域存在短缺风险、公告机构产能瓶颈在何处、经济运营商与医疗服务提供方各自面临何种障碍。正因如此，欧盟委员会健康与食品安全总司（DG SANTE）通过欧洲卫生与数字执行局（HaDEA）委托开展了一项专题研究，即"支持监测欧盟市场医疗器械可用性的研究"（Study supporting the monitoring of availability of medical devices on the EU market）。

### 1.2 研究项目与仪表盘的诞生

该研究于2022年12月启动，为期36个月（至2025年12月）。研究由奥地利国家公共卫生研究所（Gesundheit Österreich GmbH/GÖG）牵头，联合Areté与Civic Consulting共同实施。研究的核心产出之一，即为欧盟委员会开发的医疗器械可用性监测仪表盘（Dashboard）。该仪表盘汇总了来自不同利益相关方的调查数据，并与欧盟委员会此前针对公告机构开展的调查数据进行了可比性整合。

2026年7月14日，仪表盘3.5版正式发布。这一版本标志着该研究在方法学成熟度与数据颗粒度上的显著跃升：它首次实现了三轮经济运营商调查（2023年底、2024年底、2025年底）与医疗服务提供方调查（2024年）的系统性整合，并通过增强的数据可视化功能，为制造商、公告机构和主管当局提供了更为直观的趋势分析与短缺预警能力。

### 1.3 仪表盘3.5版的监管意义

仪表盘3.5版的发布并非一项孤立的IT更新。它承载着欧盟委员会以数据驱动方式管理MDR/IVDR过渡风险的监管思路：从"被动应对短缺报告"转向"主动识别市场准入结构性风险"。对于制造商、授权代表、公告机构、主管当局乃至医疗服务提供方与采购机构而言，该仪表盘所呈现的趋势数据，正在逐步成为与法律条文并行的"事实基准"——它虽不直接增设法律义务，却为第10a条供应中断通知的触发判断、公告机构产能规划、国家主管当局的市场监督优先次序，以及采购机构的风险备源决策，提供了独立的实证参照。

从更宏观的视角看，仪表盘3.5版所代表的监测能力，是欧盟卫生安全架构（尤其是健康应急准备与响应局HERA的相关工作）在医疗器械领域的延伸。它使得器械可用性不再仅是一个商业问题或合规问题，而是被纳入公共卫生与供应安全的政策框架之中。

## 二、核心变化分析

### 2.1 第三轮经济运营商调查数据的整合（2025年底）

仪表盘3.5版最核心的内容更新之一，是纳入了2025年底开展的第三轮经济运营商调查结果。与2023年底针对制造商与授权代表的首次调查、以及2024年底的第二轮经济运营商调查相比，第三轮调查的关键价值在于其纵向深度：它构成了为期两年的连续数据链，使得欧盟委员会与利益相关方能够首次在时间序列上观察到如下关键变化：

- 不同风险等级（MDR Class I至III、IVDR Class A至D）器械的市场退出与新增趋势；
- 特定产品类别（如外科器械、植入物、诊断试剂）的供应波动方向；
- 公告机构证书转换进度与制造商提交申请之间的时间差演变；
- 中小企业相对于大型企业的合规推进速度差异。

这一纵向数据对于理解过渡期延长期（MDR至2027年12月31日/2028年12月31日；IVDR分段至2027-2029年）的实际执行质量具有不可替代的价值。它使得"过渡期延长是否真正缓解了市场退出压力"这一关键政策问题，首次获得了可量化的证据基础。

### 2.2 医疗服务提供方调查数据的纳入（2024年）

仪表盘3.5版新增了一个此前版本中相对薄弱的数据维度——医疗服务提供方的直接反馈。2024年开展的该项调查覆盖了卫生专业人员（health professionals）、卫生机构（health institutions）以及医疗器械采购机构（medical device procurement bodies），其数据反映了临床端对器械可用性的真实体验，包括：

- 特定器械类别在临床使用中的可及性变化；
- 采购过程中遇见的供应延迟、断货或替代品不兼容问题；
- 医疗服务机构自身的库存与备源策略调整情况；
- 对过渡期剩余时段内供应风险的预期。

将临床终端数据与上游经济运营商数据交叉呈现，是仪表盘3.5版在方法学上的显著进步。它打破了传统监管数据"重供应端、轻使用端"的局限，使短缺信号的验证与定位更为精准——例如，当某一类别器械的制造商退出数据与医院的采购延迟数据同时升高时，仪表盘能够提供更具说服力的因果关系提示。

### 2.3 增强的数据可视化功能

仪表盘3.5版在用户界面与数据呈现层面进行了实质性增强。根据官方说明，该版本为制造商、公告机构和主管当局等利益相关方提供了"增强的数据可视化"（enhanced data visualization）。具体体现在：

- **趋势图谱的交互性提升**：用户可以按时间轴、器械类别、风险等级、成员国或利益相关方类型进行多维度筛选与下钻；
- **短缺预警标识的直观化**：潜在短缺风险不再仅以原始数据形式呈现，而是通过颜色编码和风险等级标识进行可视化分层；
- **历史可比数据的并列展示**：该仪表盘整合了欧盟委员会此前针对公告机构所开展的调查数据，使用户能够在同一界面上同时比较公告机构端的产能数据与经济运营商端的供应数据，识别出结构性错配；
- **导出与报告功能的优化**：便于监管机构与企业将仪表盘数据嵌入内部合规年度评审与市场监督报告流程中。

### 2.4 公告机构历史调查数据的可比性整合

仪表盘3.5版延续并强化了对公告机构调查数据的整合。该研究将欧盟委员会既往针对公告机构开展的调查结果纳入同一分析框架，使得MDR/IVDR指定公告机构的认证产能、审查周期、申请驳回率等供给侧数据，与经济运营商的提交率、证书转换率、市场退出意愿等需求侧数据实现了直接对照。这一整合具有重要的政策诊断价值：它能够揭示某一时段内的"产能-需求缺口"，为委员会评估是否需要进一步调整过渡期安排、或采取额外支持措施（如增加公告机构指定优先级、优化技术文件审查效率）提供数据基础。

### 2.5 多元利益相关方覆盖的体系化

综合来看，仪表盘3.5版实际上完成了一个涵盖以下主体的全景式监测体系：

| 数据来源 | 调查时间 | 覆盖对象 |
|---|---|---|
| 第一轮经济运营商调查 | 2023年底 | 制造商、授权代表 |
| 医疗服务提供方调查 | 2024年 | 卫生专业人员、卫生机构、采购机构 |
| 第二轮经济运营商调查 | 2024年底 | 经济运营商 |
| 第三轮经济运营商调查 | 2025年底 | 经济运营商 |
| 公告机构历史调查（EC） | 既往 | 公告机构 |

这一体系的意义在于：欧盟委员会首次在一个统一平台上，将器械供应链的三大关键环节——认证供给（公告机构）、产品供给（制造商/授权代表/经济运营商）、临床需求（医疗提供方与采购方）——的数据实现了可交互的可视化对照。这是MDR/IVDR时代以实证为基础的医疗器械供应安全治理的奠基性成果。

## 三、影响分析

### 3.1 对制造商与授权代表的影响

仪表盘3.5版对制造商与授权代表而言，既是外部基准工具，也是合规预警信号源。

**第一，市场退出决策的校准基准。** 仪表盘所呈现的分类别、分风险等级供应趋势，为制造商评估自身产品组合的合规持续性提供了外部参照。如果某一产品类别的全市场退出率显著上升，而本企业同类产品仍未完成MDR/IVDR转换，仪表盘数据实际上构成了一种"沉默信号"，提示管理层应加速决策：是继续投入资源完成认证，还是有序规划退市并启动第10a条通知程序。

**第二，第10a条供应中断通知的辅助判断。** 根据MDR第10a条及IVDR第10a条，制造商在预期供应中断或终止前至少6个月，必须通知相关主管当局、公告机构（如适用）、经济运营商及医疗机构。仪表盘所提供的短缺趋势数据，可以帮助制造商识别是否存在"系统性供应中断风险"——当全市场同类产品的供应数据呈现同步下降时，制造商自身的产能波动更可能被视为系统性问题的一部分，从而强化了提前通知的必要性。

**第三，调查参与与数据质量的间接责任。** 仪表盘的可靠性取决于调查参与率与数据真实性。虽然参与调查本身并非法定义务，但主管当局在开展市场监督、评估第10a条通知充分性时，很可能将该仪表盘数据作为参考。制造商应意识到，自身在调查中的披露口径与后续在监管互动中的表述一致性问题，将面临更严格的审视。

### 3.2 对公告机构的影响

公告机构是MDR/IVDR过渡期的关键供给节点。仪表盘3.5版对其影响体现在：

- **产能规划的实证基础**：公告机构可借助仪表盘中的需求侧数据（制造商提交申请的数量、时间分布、类别分布），优化自身审核资源配置，优先处理临床需求紧迫或市场退出风险较高的产品类别；
- **透明度带来的绩效压力**：历史公告机构调查数据的纳入，使得各公告机构的审查周期、驳回率、产能利用率等指标在更广的范围内被比较和审视，这将间接推动公告机构提升审核效率与一致性；
- **与主管当局的协同预警**：当仪表盘显示某一类别器械的供应快速下降、而公告机构该类别认证申请数量同步下降时，公告机构可主动与主管当局沟通，探讨加速路径或过渡期支持措施。

### 3.3 对行业的整体影响

对医疗器械行业整体而言，仪表盘3.5版的发布强化了一个长期趋势：**合规透明度正在从"结果导向"（是否获得证书）向"过程导向"（转换进度如何、供应风险何在）延伸。** 这意味着：

- 行业协会与贸易组织需要更系统地将仪表盘数据纳入对会员的指导中，帮助中小企业从"被动等待证书"转向"主动监测市场信号"；
- 投资界与并购交易中的尽职调查，将越来越多地引用此类公开监测数据，作为评估目标公司器械组合过渡期风险的外部依据；
- 仪表盘所揭示的结构性短缺风险，可能构成欧盟委员会未来采取进一步立法或政策干预（如特定产品类别的针对性过渡期调整、公告机构产能的定向扩增）的触发条件。

### 3.4 对患者、使用者与采购机构的影响

对患者、临床使用者与采购机构而言，仪表盘3.5版首次提供了一个可公开获取的、跨成员国的器械供应趋势视图。采购机构可以据此：

- 在招标与集中采购协议中，预先评估特定产品类别的断供风险，设置多源采购（multi-sourcing）条款；
- 对临床高度依赖但市场退出信号明显的器械，提前启动替代品评估或库存警戒线调整；
- 将仪表盘数据与医院内部的耗材管理信息系统对接，建立机构层面的器械可用性预警机制。

从患者安全角度看，仪表盘所推动的供应透明度最终服务于一个核心目标：避免因过渡期合规导致的"无器械可用"或"被迫使用非最优替代品"的临床风险。

## 四、合规建议

### 4.1 对制造商与授权代表的行动建议

1. **立即审阅仪表盘3.5版数据，开展产品组合基准比对。** 将本企业已完成MDR/IVDR认证、正在申请中、尚未启动申请以及计划退市的产品系列，按器械类别与仪表盘趋势数据逐项比对。识别出"全市场退出率上升但本企业尚未启动转换"的高风险产品。

2. **建立内部仪表盘监测机制。** 指定法规事务或供应链管理部门负责定期（建议每季度）跟踪仪表盘更新，并将关键变化纳入管理层评审议程。特别关注与自身产品组合直接相关的类别趋势。

3. **完善第10a条供应中断通知的内部触发流程。** 以仪表盘数据为重要参考之一，制定量化的通知触发标准（例如：某类别产品全市场供应下降连续两个调查周期超过一定阈值，且本企业该产品供应亦呈下降趋势），纳入质量管理体系的变更与供应中断管理程序。

4. **积极配合后续调查。** 若收到欧盟委员会、HaDEA或研究联盟发起的后续调查请求，应确保数据真实、口径一致，并指定具备跨部门视野的人员统筹填报，避免仅由单一部门提供片面数据。

5. **利用仪表盘数据支撑过渡期资源优先级决策。** 在CE证书转换资源有限的情况下，优先投入临床不可替代性强、市场供应集中度高、仪表盘显示短缺风险上升的产品类别。

### 4.2 对公告机构的行动建议

1. **将仪表盘需求侧数据纳入年度审核资源规划。** 根据申请提交趋势与类别分布，动态调整技术文件审查团队的学科配置；

2. **主动向主管当局通报结构性风险。** 若发现特定类别申请量骤降或与市场退出数据交叉印证，应主动与相关主管当局沟通，探讨加速审查或联合处理的可能性；

3. **关注自身历史调查数据在仪表盘中的呈现方式，核查数据一致性。** 对与既往提交数据不一致之处，应追溯原因并准备说明，以备委员会或主管当局质询。

### 4.3 对主管当局的行动建议

1. **将仪表盘数据与第10a条通知信息进行交叉验证。** 在收到制造商供应中断或终止通知时，对照仪表盘中的类别趋势判断该通知是否属于更广泛市场结构性问题的组成部分，并据此决定是否需要启动国家层面或欧盟层面的协调行动。

2. **利用仪表盘识别优先市场监督对象。** 对仪表盘中显示供应快速下降或退出集中的器械类别，加强该类产品的上市后监督与警戒数据审查。

3. **参与后续数据贡献与反馈。** 主管当局作为MDR/IVDR实施的核心执法主体，其数据反馈（尤其是公告机构指定与监督相关的信息）对仪表盘的持续完善具有关键作用。

### 4.4 对医疗服务提供方与采购机构的行动建议

1. **将仪表盘纳入机构层面的器械供应风险评审。** 建议采购部门在每一采购年度开始前，以仪表盘最新版本为基准，识别高风险产品类别并制定备源计划；

2. **在集中采购和框架协议中预设供应中断应对条款。** 包括替代品预先评估、安全库存要求、供应商定期报告义务等。

3. **继续参与医疗服务提供方调查。** 医疗机构与采购端的真实反馈是仪表盘数据质量的根基，应鼓励相关人员重视并如实填报。

### 4.5 对行业协会与贸易组织的行动建议

1. **开展针对会员的仪表盘解读培训。** 帮助中小企业理解仪表盘数据的监管意涵，避免因信息不对称而延误合规决策；

2. **汇总会员层面的共性风险并向委员会反馈。** 将仪表盘数据与会员实践中的具体障碍相结合，形成有据可依的政策建议。

## 五、时间线与关键日期

| 时间节点 | 事件 | 监管意涵 |
|---|---|---|
| 2017年5月 | MDR与IVDR正式通过 | 新监管框架确立 |
| 2021年5月26日 | MDR正式适用 | 过渡期开始 |
| 2022年5月26日 | IVDR正式适用 | 过渡期开始 |
| 2022年12月 | 欧盟可用性监测研究正式启动（为期36个月） | 实证监测基础建立 |
| 2023年3月 | 《条例（EU）2023/607》通过 | MDR过渡期延长；引入第10a条 |
| 2023年底 | 第一轮经济运营商调查（制造商与授权代表） | 基线数据采集 |
| 2024年 | 医疗服务提供方调查（卫生专业人员、机构、采购机构） | 临床需求端数据补充 |
| 2024年6月 | 《条例（EU）2024/1860》通过 | IVDR过渡期分段延长 |
| 2024年底 | 第二轮经济运营商调查 | 纵向数据集扩展 |
| 2025年底 | 第三轮经济运营商调查；研究期结束（2025年12月） | 完整纵向数据链形成 |
| 2026年7月14日 | 仪表盘3.5版发布 | 多源数据整合与增强可视化上线 |
| 2027年12月31日 | 高风险器械MDR过渡期截止（部分） | 制造商需完成转换或退市 |
| 2028年12月31日 | 中低风险器械MDR过渡期截止（部分） | 最终合规期限 |
| 2027-2029年（分段） | IVDR过渡期陆续截止 | 体外诊断器械合规节点 |

需要特别指出的是，仪表盘3.5版虽然发布于研究期结束（2025年12月）之后，但其作为该研究最终阶段的核心交付成果，承载的是对整个36个月研究周期内所采集数据的整合与呈现。相关方不应将其视为一个静态终点，而应理解为欧盟委员会持续监测器械可用性、动态评估MDR/IVDR过渡影响的工具基础。未来，随着委员会对过渡期后市场格局的关注深化，该仪表盘所奠定的多源数据整合方法论，极有可能被延续或扩展至更广泛的卫生供应安全监测体系中。

**结论**：仪表盘3.5版是欧盟委员会以实证数据驾驭MDR/IVDR过渡风险的重要里程碑。对于所有受MDR/IVDR管辖的市场参与者而言，它不仅是一个可视化工具，更是一个战略预警系统。相关方应将其纳入合规规划与供应安全管理的日常实践，以数据为锚，主动应对过渡期最后阶段的合规与供应链双重挑战。
