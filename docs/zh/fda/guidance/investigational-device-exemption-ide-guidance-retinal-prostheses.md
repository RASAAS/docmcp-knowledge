2. 范围 范围
本文件限于视网膜假肢(即视网膜上或视网膜下植入的视像假肢器械,以及全球外表面或外表下安装的假肢器械)。使用电刺激手段,为患有变性视网膜畸形症的人提供某种程度的视觉感知。
本文件不适用于刺激视神经或视觉皮层或横向后生核等其他较高大脑区域的假肢。此外,含有药物或生物产品的假肢可能是混合产品。FDA中心对混合产品负有监管责任,中心由该产品的主要行动模式决定,在某些情况下,可能不是CDRH。欲了解关于合并产品管辖权的补充资料或提交指定请求书,请参看FDA合并产品办公室(见[参见原文链接])。
FDA认为,本指南文件所述器械是21 CFR 812.3(m)所界定的重大风险器械。因此,在美国临床调查中打算使用这些器械的申办者必须向FDA提交IDE申请,并在开始调查之前(21 CFR 812.20(a)),获得FDA和IRB批准申请。除了要求获得FDA核准的IDE之外(21 CFR Part 812),还需要获得FDA核准的IDE。这类研究的申办者必须遵守关于机构审查委员会(IRBs)的条例(21 CFR Part 56)和知情同意(21 CFR Part 50)。

4. 风险分析
您必须在调查计划中描述和分析调查对象将面临的所有增加的风险,以及尽量减少这些风险的方式(21 CFR 812.25(c))。您应在 IDE 应用中描述您进行风险分析的方法,并在该过程中包含足够详细的内容以支持所选方法。
为满足这一风险分析要求,我们建议你对电子部件和电路进行故障模式和风险分析摘要。您的失灵模式和风险分析摘要应查明并评估任何潜在的电子危害/故障造成的风险,以及这些风险的潜在严重程度,以及如何消除或减少这些障碍。
我们建议你提供一个可追踪矩阵,显示你如何验证你的视觉假肢器械电子器械中的减轻风险功能。
5. 试验数据的内容和格式
a. 目录表. 我们建议您在提交材料的开头列入一个目录,列出已经进行的具体测试。
b. 进行的测试、数据摘要和结论。 每次进行的测试,你都应说明研究的目的、所用方法(议定书)、结果和结论。报告应载有适用于贵组织器械的下列内容:(dev.) 测试数据。
我们还建议你为每次试验提供你结论的叙述性摘要,并解释结果是否支持你器械的安全性和性能。
