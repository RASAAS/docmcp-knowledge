# 试用与企业开通

每个新用户有一次免费试用。删掉账号后不能继续注册试用。已经注册的企业账号要先完成认证和合同，账户页才会出现付款。下面按常见情形说明该怎么做。

## 免费试用有一次

自行注册时，选「个人」或「企业」，并选「免费试用」，开通的都是同一种试用：

- 期限 30 天
- 额度 150 Credits
- 账户页套餐显示为 Trial

用过这次试用之后，再用同一邮箱或同一手机号自行注册，会提示该邮箱已经使用过免费试用。改选「企业」并仍然选择「免费试用」，结果相同。

试用账号还在时，留着这个账号继续办理认证和付款。删除后不能靠再注册拿第二次试用。

## 账号还在：改为付费企业

1. 继续使用现有账号。账号若仍是「个人」，联系我们改为「企业」后再认证。
2. 打开账户页，完成手机号验证，提交企业认证。
3. 认证状态为「审核中」时，页面只有等待说明。此时没有合同，也没有付款。
4. 我们审核通过后，重新打开账户页。状态变为「已通过」后，同一页出现「合同签约」。
5. 选择套餐和周期，生成合同并确认。
6. 合同生效后，下方出现订阅与付款。从试用购买付费套餐，付款后立即生效，额度改为所购套餐的月度 Credits。已单独购买的充值额度会保留。

企业账号可以购买 Starter 或 Basic。这两个套餐可以正常付费使用。创建团队需要企业账号，并且套餐为 Pro、Max 或 CRO。

## 加入已有的 Pro、Max 或 CRO 团队

邀请方须已是企业账号，套餐为 Pro、Max 或 CRO，并且已经创建团队。

被邀请人打开团队邀请链接，用链接里的那个邮箱完成注册。已经用过试用、账户未删除的用户，可以使用邀请链接加入团队。

加入后：

- 使用团队共享 Credits，不再单独发放个人试用额度
- 须开启双重验证
- 席位含所有者在内：Pro 为 3 个，Max 与 CRO 为 10 个。发出后尚未接受的邀请会占用一个席位

不打开邀请链接、在普通注册页填写同一邮箱，仍然会被拒绝。

已有 CRM 门户账号时，须通过制造商发来的团队邀请链接登录并接受，之后才能使用助手。门户账号本身不等于助手套餐。详见 [助手与 CRM 的区别](./crm-and-assistant)。

## 账号已经删除

自行注册会被拒绝。可以使用已签约的付费邀请码重新开户。

### 使用已签约的付费邀请码重新开户

注册时选择「企业」和「已签约」，填入邀请码。公司名称须与邀请码上绑定的名称一致，括号的全角或半角可以不同。

邀请码上的套餐须为 Starter、Basic、Pro 或 Max。套餐仍是 Trial 的邀请码，对已经用过试用的邮箱和手机号无效。

开户额度与期限以这张邀请码为准。这是付费开户，不是第二次试用。

## 邀请码什么时候生效

邀请码只在新注册、并且选择「企业」加「已签约」时生效。

选「免费试用」时，页面上即使填了邀请码，系统也不读取。账号仍是 30 天试用、150 Credits。

账号注册完成之后，不能把邀请码补进这个账号。未使用的邀请码会一直留到它自己的有效期结束，或由我们作废。它不会改掉已有账号的套餐和额度。

企业认证一旦进入「审核中」或「已通过」，同一公司名称不能再注册第二个企业账号。

账户页显示的是 Credits。试用和 Starter 的默认额度都是 150 Credits。

## 付款之后额度何时变化

| 当前状态 | 购买内容 | 何时生效 |
| --- | --- | --- |
| 试用 | 任一付费套餐 | 付款后立即生效，额度改为新套餐额度 |
| 已经是某付费套餐 | 再买同一套餐 | 当前周期结束时生效。邀请码里设过的较小额度，不会在这次付款时补成套餐满额 |
| 月付 | 升到更高套餐 | 可选立即生效，或等到当前周期结束。立即生效时，套餐额度改为新套餐额度 |
| 年付 | 升到更高套餐 | 当前年度结束时生效 |
| 年付 | 同一套餐提前续费 | 按 [套餐与定价](./pricing) 中的提前续费规则执行 |

单独购买的充值额度跨周期保留。降级在当前周期结束后生效。已支付的订阅费用不退。

## 账户页上看不到升级或付款

按账户页上的认证状态处理：

| 账户页显示 | 下一步 |
| --- | --- |
| 企业认证「审核中」 | 等待审核。通过后重新打开账户页 |
| 企业认证「已通过」，还没有合同 | 在同一页完成「合同签约」 |
| 合同尚未确认 | 付款区仍不显示 |
| 合同已生效 | 出现订阅、升级和付款 |
| 你是团队成员，不是所有者 | 订阅由团队所有者办理 |

认证通过后若仍看到「审核中」，先刷新页面再查看。

## 情形对照

| 情形 | 结果 |
| --- | --- |
| 删除试用后，自行注册并选择免费试用 | 拒绝 |
| 试用账号还在，完成认证、签约并付款 | 可以，立即变为所购套餐 |
| 给用过试用的邮箱发放 Trial 邀请码 | 拒绝 |
| 用 Starter 及以上的已签约邀请码新注册 | 可以，按邀请码的套餐和额度开户 |
| 注册时选了免费试用，同时填写邀请码 | 邀请码不生效，仍为 30 天、150 Credits |
| 注册完成后再提交邀请码 | 不生效 |
| 公司认证已提交或已通过，再用同一公司名注册 | 拒绝 |
| 已经用过试用、账户未删除，使用 Pro、Max 或 CRO 的团队邀请链接 | 可以加入。须使用该链接和被邀请邮箱，使用团队额度，并开启双重验证 |
| 企业购买 Starter 或 Basic | 可以付费使用，不能创建团队 |
| 已是 Starter，再付一次 Starter，希望立刻补满额度 | 当前周期结束时才生效 |
