# Reguverse 助手 与 CRM：有何不同？

许多用户在看到 [CRM 门户申请页](https://crm.reguverse.com/request-access) 时会问：**「助手和 CRM 是不是两个平台？已有助手账号还要再申请吗？额度会不会混在一起？」**  
本文说明二者关系，以及已有 Reguverse 助手账号时该怎么做。

## 一句话结论

| | **Reguverse 助手** | **Reguverse CRM** |
|---|---|---|
| 是什么 | AI 合规文档工具（Word 插件 / Web） | CRO 客户协作与项目管理门户 |
| 主要使用者 | RA / 制造商自建文档 | CRO 团队 + 其客户 |
| AI 能力 | 自有工作流与文档生成 | **调用同一套助手 API**，能力同源 |
| 账号 | Reguverse 账号（邮箱登录） | **同一套 Reguverse 账号**（SSO） |
| 申请「门户访问」 | 不适用 | 客户申请与 CRO 协作入口，**不是**另购一套助手 |

二者**不完全相同**：产品形态与用途不同；但**登录身份与 AI 引擎同源**。CRM 不会替代助手，也不会要求您再注册一个无关的「第二套 AI 产品」。

## Reguverse 助手是什么？

**Reguverse 助手**（产品内常简称 Assistant / docmcp）面向法规文档编写：

- 在 Microsoft Word 或 Web 中运行 AI 工作流（临床评价、风险管理、GSPR、NMPA 等）
- 按套餐提供功能权限与 **Credits** 额度
- 适合制造商、顾问自行使用工具完成合规文档

详见 [套餐与定价](./pricing)、[快速开始](./get-started)。

## Reguverse CRM 是什么？

**Reguverse CRM**（[crm.reguverse.com](https://crm.reguverse.com)）是面向 **CRO / 咨询机构运营** 的协作平台：

- 客户、项目、任务、报价、发票、消息、表单
- **客户门户**：客户查看进度、确认文档、上传资料、参与任务
- CRO 侧可在项目中触发与助手相同的 AI 文档能力（经 API 调用）

CRM 的 **CRO 套餐**在助手套餐体系中额外开放 CRM 功能（见 [套餐与定价](./pricing) 中的 CRO 说明）。  
客户申请的「门户访问」是为了进入 **某家 CRO 的协作空间**，而不是单独购买助手订阅。

## 已有助手账号时，申请 CRM 门户意味着什么？

1. **请使用同一邮箱**填写 [申请门户访问](https://crm.reguverse.com/request-access)。
2. CRO / 平台审核通过后，您会收到邀请；用**原有** Reguverse 密码登录即可激活门户，无需新建无关账号。
3. 申请通过后，您获得的是 **客户门户权限**（查看项目、任务、消息、文档确认等），**不会**自动把您变成 CRO，也**不会**取消或替换您原有的助手订阅。
4. 若您只是自己用助手写文档、不需要与某家 CRO 协作，通常**不必**申请 CRM 门户。

::: tip 登录入口
- 助手：Word 插件 / 助手 Web（如 `app.reguverse.com`）
- CRM：`https://crm.reguverse.com`（同一邮箱；CRM 侧二次验证为邮箱 OTP，与助手端 Authenticator 2FA 通道不同）
:::

## 额度（Credits）怎么算？

这是咨询中最常见的疑惑点：

- **助手自用**：您在助手里跑工作流 / 生成文档，消耗的是**您自己（或您所属组织）套餐的 Credits**。额度与工作量相关——文档多、文献多时消耗更大；常规使用下各套餐额度一般够用，不足可 Topup。详见 [套餐与定价 · Credits](./pricing#credits-说明)。
- **经 CRM 由 CRO 代为生成**：AI 仍走助手同一 API；计费落在**实际发起调用的计费主体**（通常是 CRO 团队侧额度），而不是「客户再买一套无关额度」。客户申请门户本身**不扣**助手 Credits。
- **固定服务合同 vs 工具额度**：若您与 CRO 签订了「项目期 / 固定服务费」类合同，那是**咨询服务商业安排**；助手 Credits 仍是工具侧用量计量。二者不要混为一谈——服务费不等于无限 AI 额度，工具额度也不等于咨询报价。

::: info 协作项目中的文档权限
在 CRM 客户门户中，由 **CRO 创建并运营** 的项目任务可使用 CRO 套餐下的全部高级文档能力（与 Max 同级功能 + CRM）。此时 AI 生成走的是 **CRO 侧额度与权限**，不取决于客户自己的助手套餐等级。客户若另行用自己的助手账号独立写文档，则仍按其自身套餐与 Credits 计费。
:::

## 常见问题

### 这两个平台是不同的吗？

**用途不同，能力同源。**  
助手 = AI 文档工具；CRM = CRO 运营与客户门户。AI 生成能力相同（CRM 调用助手 API）。登录用同一套 Reguverse 账号体系。

### 我已经有助手账号，还要申请门户吗？

仅当您需要与某家 CRO / 平台团队在 CRM 中协作时才需要申请。申请时填同一邮箱即可。

### 申请门户会不会覆盖我原来的助手订阅？

不会。门户访问是协作权限，与助手套餐订阅相互独立（除非您另行变更订阅）。

### CRM 里生成文档会不会把我个人助手额度用光？

不会因为「申请门户」而扣 Credits。CRO 在 CRM 项目任务中创建并生成文档时，使用的是 **CRO 的额度与高级功能权限**；只有您用自己的助手账号独立操作时，才会消耗您自己的套餐 Credits。
