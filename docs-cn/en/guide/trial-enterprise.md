# Trial and enterprise signup

Each new user receives one free trial. After the account is deleted, a new trial cannot be registered. An enterprise account that is already registered must finish verification and the contract before payment appears on the Account page. The sections below cover the usual cases.

## One free trial

Self-service registration as Personal or Enterprise, with Free Trial selected, opens the same trial:

- 30 days
- 150 Credits
- The Account page shows the plan as Trial

After this trial has been used, registering again with the same email or the same phone number shows that the email has already used its free trial. Choosing Enterprise and still selecting Free Trial has the same result.

While the trial account still exists, keep it and continue with verification and payment. After deletion, registering again does not provide a second trial.

## If the account still exists: switch to a paid enterprise plan

1. Keep using the current account. If it is still Personal, contact us to change it to Enterprise before verification.
2. Open the Account page, finish phone verification, and submit enterprise verification.
3. While the status is Under review, the page only shows a waiting note. There is no contract and no payment.
4. After we approve the verification, open the Account page again. When the status is Approved, Contract Signing appears on the same page.
5. Choose the plan and billing period, generate the contract, and confirm it.
6. After the contract takes effect, subscription and payment appear below. Buying a paid plan from a trial takes effect immediately, and Credits change to that plan's monthly amount. Credits bought separately as a top-up are kept.

An enterprise account can buy Starter or Basic. Both plans can be paid and used. Creating a team requires an enterprise account on Pro, Max, or CRO.

## Joining an existing Pro, Max, or CRO team

The person sending the invitation must already have an enterprise account on Pro, Max, or CRO, and must already have created the team.

The invited person opens the team invitation link and registers with the email on that link. Users who have already used the trial and have not deleted the account can join a team with the invitation link.

After joining:

- The member uses the team's shared Credits. A separate personal trial allowance is not issued.
- Two-factor authentication must be turned on.
- Seats include the owner: Pro has 3, Max and CRO have 10. An invitation that has been sent and not yet accepted holds one seat.

Registering the same email on the normal registration page, without opening the invitation link, is still refused.

If you already have a CRM portal account, sign in through the team invitation link sent by the manufacturer and accept it before using the Assistant. A portal account is not an Assistant plan. See [Assistant vs CRM](./crm-and-assistant).

## If the account has been deleted

Self-service registration is refused. You can open a new account with a contracted paid invitation code.

### Open a new account with a contracted paid invitation code

When registering, choose Enterprise and Already Contracted, and enter the invitation code. The company name must match the name bound to the code. Full-width and half-width parentheses are treated as the same.

The plan on the code must be Starter, Basic, Pro, or Max. A code that is still on Trial does not work for an email or phone number that has already used a trial.

The allowance and term follow that invitation code. This is a paid account, not a second trial.

## When an invitation code takes effect

An invitation code takes effect only for a new registration that selects Enterprise and Already Contracted.

If Free Trial is selected, the system does not read an invitation code entered on the page. The account is still a 30-day trial with 150 Credits.

After registration is complete, the code cannot be added to that account. An unused code remains until its own validity ends, or until we revoke it. It does not change the plan or Credits of an account that already exists.

Once enterprise verification is Under review or Approved, the same company name cannot be used to register a second enterprise account.

The Account page shows Credits. Trial and Starter both include 150 Credits by default.

## When Credits change after payment

| Current state | Purchase | When it takes effect |
| --- | --- | --- |
| Trial | Any paid plan | Immediately after payment. Credits change to the new plan |
| Already on a paid plan | The same plan again | At the end of the current period. A smaller amount set on an invitation code is not filled up to the full plan amount by this payment |
| Monthly | A higher plan | Immediately, or at the end of the current period. If immediate, plan Credits change to the new plan |
| Annual | A higher plan | At the end of the current year |
| Annual | Early renewal of the same plan | Follow the early-renewal rules on [Plans & Pricing](./pricing) |

Credits bought separately as a top-up stay across periods. A downgrade takes effect at the end of the current period. Subscription fees already paid are not refunded.

## Upgrade or payment is not on the Account page

Use the verification status on the Account page:

| What the Account page shows | Next step |
| --- | --- |
| Enterprise verification Under review | Wait for review. Open the Account page again after approval |
| Enterprise verification Approved, no contract yet | Finish Contract Signing on the same page |
| Contract not yet confirmed | The payment area stays hidden |
| Contract in effect | Subscription, upgrade, and payment appear |
| You are a team member and not the owner | The team owner handles the subscription |

If the status still shows Under review after approval, refresh the page.

## Cases

| Case | Result |
| --- | --- |
| After deleting a trial, register again and choose Free Trial | Refused |
| The trial account still exists, and verification, contract, and payment are completed | Allowed. The account switches to the purchased plan immediately |
| A Trial invitation code is issued to an email that has already used a trial | Refused |
| A new registration uses a contracted invitation code for Starter or above | Allowed. The account opens on the plan and Credits of that code |
| Free Trial is selected and an invitation code is also entered | The code does not apply. The account is still 30 days and 150 Credits |
| An invitation code is submitted after registration | It does not apply |
| Verification has been submitted or approved, and the same company name is used to register again | Refused |
| The trial has been used, the account has not been deleted, and a Pro, Max, or CRO team invitation link is used | The user can join. The link and the invited email are required. The member uses team Credits and must turn on two-factor authentication |
| An enterprise buys Starter or Basic | The plan can be paid and used. A team cannot be created |
| The account is already Starter, and Starter is paid again in order to fill Credits immediately | It takes effect at the end of the current period |
